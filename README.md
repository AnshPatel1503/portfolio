## ⚙️ Run Locally

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/portfolio.git
```

Go into the project:

```bash
cd portfolio
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open:

```text
http://localhost:5173
```
